# Daybreak blog (draft)

Static blog page for "Daybreak: Standup Zero for Switch". No build step.

Run: open `index.html`, or `python3 -m http.server` and visit http://localhost:8000.

## Files
- `index.html`: content, in the agreed five-section order
- `styles.css`: night/dawn themes, layout
- `script.js`: theme toggle, draft-notes toggle, copy button, side-rail highlight
- `assets/`: drop real captures here

## Replace placeholders
Yellow `tbc` marks and "Draft note" boxes flag anything unverified. Hide them with the "Draft notes" button, and delete them before publishing.

| File | Slot |
| --- | --- |
| `assets/demo.gif` | Hero demo |
| `assets/brief.png` | Section 2 screenshots |
| `assets/friday-rule.gif` | Section 3 Friday-rule proof |

Also fill in: team name, repo URL (`#repo-link`, `.repo-a`), verified setup command, origin sentence, test results, lessons and limitations.
